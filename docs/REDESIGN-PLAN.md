# OutDesign「創作場域」改版企劃

日期：2026-10-23。先完成需求、現況與研究，再依下列階段實作；使用者授權企劃完成後直接執行及沿用既有發佈流程。

## 1. 目標與範圍

- 改版首頁、關於、筆記、資源：構圖、文案、動態、行動版、空狀態一起設計。
- 與作品頁共享紙白／石墨／金屬、精準留白、細線索引的氣質，但不複製 3D 陣列、物件檢視、浮動工具列及收藏搜尋。
- 作品頁維持設計；新增修正選取物件返回陣列時短暫解除渲染、消失後重現的問題。
- 先前暫緩的低效能壓力研究仍暫緩。不得以降低作品解析度作為本次改版手段。
- 保留作者編輯、歷史、圖層、腳本、深淺色、動態偏好與既有資料。不得覆寫使用者 .local 或遠端草稿。

## 2. 現況與資訊盤點

現有非作品頁使用相同頁首、巨型雙句標題與玻璃卡片。首頁月景與內頁內容缺少連續敘事，深淺色之間的視覺重量不同。資源空白時欠缺明確回饋；部分預設文字仍為作者模式操作說明，公開信箱是示範值。作品頁已有具體且有辨識度的材質、索引與空間，應抽取氣質而非複製操作。

資料來源為 build 時的已發佈內容，不是單純 seed。改寫採「精確辨識舊預設文案後更新呈現，使用者自訂優先」；不捏造履歷、獎項、客戶、作品或聯絡資訊。真正筆記、附件及上傳圖片全部保留。

## 4. 創意方向與設計系統

概念：**創作場域 / A practice in becoming**。將個人網站視為正在編輯的創作出版物：每一頁都是一個清晰的章節。紙張般的留白、石墨文字與精準編排構成視覺辨識，少量赤陶色標記現在的位置。

- 排版：12 欄桌面／手機單欄；中文字為閱讀主體，英文作索引。大字只出現在敘事節點，不讓所有區塊爭搶注意力。
- 材質：溫暖紙白、石墨黑，低飽和銀與赤陶。深色同步設計，不把淺色單純反相。
- 主視覺：依使用者最新回饋撤下生成雕塑，後續不使用生圖。改以文字尺度、留白、描邊字與原生捲動的排版位移呈現；保留使用者自訂圖像。
- 邊框與幾何：開放式區域、水平細線、大尺寸取景框；不再沿用玻璃卡片矩陣。
- 控制：沿用全站單一「導覽」入口及單一設定入口。頁內連結各有目的；不添加游標替身、拖曳導航、輪播或另一套搜尋／收藏。

## 5. 每頁敘事與文案

| 頁面 | 結構與主要內容 | 互動重點 |
| --- | --- | --- |
| 首頁 | OUTDESIGN 大型字標 →「讓想法，有了形狀。」與錯位字行 → 單一作品入口 → 關於／筆記／資源編輯式頁面索引 | 字行分層揭幕、主視覺輕微取景位移、作品入口線條展開、索引行的方向回饋 |
| 關於 |「好奇，是一種工作方式。」→ 原有介紹／創作領域 → 觀察、組織、實作三步方法 → 真實聯絡與可選音樂 | 章節依閱讀順序顯現、引言與段落依閱讀順序揭幕；音樂按需開啟 |
| 筆記 |「把思考，留在途中。」→ 編號與分類 → 原有筆記內容可直接展開閱讀 | 原生 details，明確展開標記，閱讀內容不依賴 hover；有外部文章才提供閱讀連結 |
| 資源 |「值得留下的，也值得分享。」→ 真實檔案列表／明確空狀態 → 使用說明 | 整行檔案連結、檔案標籤、外開標記；不放假下載按鈕 |

只改寫已知預設／示範文字；自訂標題、聯絡資料、真實文章內容優先保留。示範信箱不呈現可寄送的聯絡行動。

## 6. 動態規格與技術落地

- 首屏：載入完成後 650–900ms 字行與主視覺錯開進場；不延長既有 loader 等待。
- 捲動：一次性 reveal 以 IntersectionObserver；主視覺的取景及線條由單一、事件觸發 RAF 更新，無永久跑動迴圈。
- hover/focus：180–320ms 箭頭／底線／行背景回饋，鍵盤與觸控都能取得相同資訊。
- reduced motion：停止位移、縮放與遮罩動畫，內容立即可見。隱藏頁籤或作者開啟時停止更新；卸載清理 observer、event、RAF。
- 非作品頁建立獨立 scoped component/CSS；不讓新樣式覆蓋 WorkLab。
- 保留 elementProps、SourceValue、EditableText、工作區自訂 panels、section 順序、腳本及 BASE_PATH。
- 作品返回問題由獨立修正處理；驗證選取、返回、快速切換與完整陣列可見性。

## 8. 驗收底線

每頁一個 H1、單一作者入口與主要導覽；主要行動有明確文字及真正目的。無重疊、截字、互相遮擋或依賴 hover 才能使用的內容。無 JavaScript 時內容仍可讀。資源無資料即誠實空狀態。作品頁除已列返回修正外保持既有設計。自訂內容、圖片、資料庫草稿與驗證機制不變。

## 最新 UI／UX 修訂（使用者回饋）

- 不使用新增生圖；未採用的折帶素材已移出 public，正式網頁無請求。
- 新增研究：Dennis Snellenberg（https://dennissnellenberg.com/）實際檢視大字與留白構圖；Rauno（https://rauno.me/）的簡短明確資訊層級。學習節奏與細節，不搬用肖像、案例圖片、履歷或文案。
- 首頁以主標與側註形成單一焦點；英文描邊字帶只隨原生捲動有限移動，不自動播放、不另造互動控制。
- 深淺色設定面板需獨立配色 tokens；原生選單與 option 顯式前景／背景／color-scheme，避免透明或相同色。
- 公開與作者拉條皆檢查軌道進度、滑塊、數值與鍵盤焦點，觸控可操作，不以 hover 才顯示狀態。
- 全面檢查導覽目的／重複控制、視覺層級、字級／留白、狀態對比、鍵盤／觸控、空結果、資料保護；問題需落成修正與驗證，不以「已分析」替代完成。
