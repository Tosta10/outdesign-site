## 問題來源

原本共用樣式把設定的 `select` 改成透明背景，原生 `option` 又沒有明確配色。一般頁面、作品與編輯預覽各有不同的文字／背景變數，深色模式因此可能產生近似同色的控制。音量仍使用 `appearance:auto`，軌道與拇指外觀交由平台決定，無法清楚呈現目前進度。

## 完成的設計

設定面板採用獨立的 `--pref-*` 色票，表面、控制、主要文字、次要文字、邊框、強調色及強調色上的文字各有固定用途。網站一般配色仍由既有頁面控制；設定樣式限定在 `.site dialog.experience-settings`，不會改動作者外框工具。

音量保留原生 `range` 元素，以 CSS 提供 4 px 軌道、24 px 拇指及 44 px 操作高度。既有偏好同步同時更新 `--range-progress`，讓拖曳、鍵盤、預設按鈕與已儲存音量呈現相同狀態。數值顯示使用等寬字，選中預設有實色底與勾號，開關有位置和底色兩種狀態線索。

保留原生選單與滑桿語意，支援鍵盤、觸控、輔助技術及強制色彩模式；沒有另加一套重複的自製選項選單。
