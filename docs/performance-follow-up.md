# 後續任務：整站與作者模式效能

使用者於 2026-10-22 指定先記錄，待目前介面、卡帶破圖與互動修正完成後另行處理。

- 深入分析低效能設備的 CPU、GPU、記憶體、貼圖、載入與主執行緒瓶頸。
- 優化後維持完整功能和動態效果，不以關閉必要互動或直接取消動畫作為完成標準。
- 分開量測公開網站、作者入口未解鎖、作者圖層、積木、即時縮圖、互動預覽等狀態，確認作者模式是否導致卡頓。
- 評估未解鎖時的靜態預覽、延後初始化、閒置和背景暫停；解鎖或需要操作時才啟動必要資源，確保切換順暢。
- 以真實低階手機或等效限制、軟體 GPU、長時間操作和連續快速輸入驗證。記錄幀時間、輸入到畫面延遲、長任務、記憶體和復原情況，並保留優化前後證據。
- 檢查場景、作者預覽、觀察器、事件與背景迴圈的資源生命週期，避免重複初始化或隱藏後仍持續工作。

本項為後續研究與實作清單；目前尚未宣稱完成整站效能優化。
