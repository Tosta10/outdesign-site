# 工程藍圖作者工作區

## 首頁保留原貌

依使用者最後指示，首頁保留原本月面主視覺、「保持好奇…」介紹卡及精選作品。僅替換品牌 Logo／Favicon、合併重複作者入口與導向，沒有預設泡泡、新展示面板或水波。已移除取消需求的球體、粒子、fBm、GSAP 與 simplex-noise 代碼及相依套件。

依最終要求，水面模組、Shader、Three.js 與型別依賴已全部移除。沒有隱藏的水波開關或持續背景渲染。

## 選取與屬性

- 點選介紹卡顯示關於內容；點選精選卡顯示對應作品；點選品牌顯示全站設定；點選靜態介面文字顯示該文字。
- 選取後屬性面板回到頂端，精準文字欄位可直接取得焦點。加入子積木收在次要折疊區。
- `presentation.copy` 儲存導覽、頁面介紹與區塊標籤；`presentation.elements` 儲存型別化內距、圓角、透明度、字級、顏色與隱藏狀態。
- 主視覺、介紹卡圖片與 Logo 都能替換；Logo 發布後也用於 favicon。隱藏的內建元素在編輯時仍可選取。
- 任意 JavaScript／HTML 不在作者內容中執行，URL、顏色與尺寸均由共用 schema 驗證。

## 積木模式

`BlockLibrary.tsx` 與 `blocks.ts` 提供文字組、圖文雙欄、內容面板、三欄網格及行動入口。可點選插入或拖到畫布／現有 frame。每次建立唯一 ID 和有效父子關係，組合插入只形成一個復原步驟。

基礎單位為 frame、text、image、link、divider，可拆解、嵌套、重排、複製、鎖定、隱藏，並支援自由拖曳、縮放及 8px 吸附。藍圖模式顯示輪廓、名稱與尺寸；一般模式保留乾淨閱讀畫布。桌面移除重複浮動工具列與左側頁面選擇清單。

## 代碼與即時預覽

展開代碼時，左側編輯、右側顯示隔離 iframe 的即時畫面。停止輸入 180ms 後驗證整站 JSON 或型別化 CSS；有效內容更新預覽，無效內容保留最後有效畫面並顯示錯誤。

預覽不會寫入草稿，只有「驗證並套用」才形成修改。右側可切換頁面及 390／1280 裝置；iframe 不執行任意腳本、提交表單或外部導航。需實際操作網站功能時使用頂部「預覽」。

## 已實作的效能改善

1. 畫布使用 memo 與 useDeferredValue，將大型頁面渲染和即時輸入控制分離；面板切換、儲存提示等狀態不再無條件重繪整頁。
2. 相同欄位 650ms 內連續輸入合併為一筆復原。資料更新仍先 clone；歷史及儲存重用不可變快照，避免再複製一次整站資料。
3. 內容簽章在 apply 時只序列化一次，儲存前／回應後與離開頁面直接比較快取簽章；維持原有序列儲存及 revision 衝突保護。
4. 代碼預覽驗證 debounce 180ms，iframe 與樣式只建立一次；無效輸入不重建畫面或觸發儲存。
5. 私人素材依 ID 快取物件 URL，避免重複取回與建立 URL；刪除／關閉釋放，關閉後完成的非同步讀取不再建立 URL。
6. 移除整套 WebGL 及水波資源。浮起、放大、柔光與描邊使用 CSS；傾斜採 Delta Time 阻尼，只在指標移動與回位期間執行 RAF，閒置後停止。

7. 圖層依 ID／父層索引一次建立，巢狀渲染由重複掃描改為線性查找；關閉的面板代碼不再持續序列化，代碼工作區簽章按內容快取。

這些改變減少工作量與輸入競爭，不代表已保證每種裝置的幀率。

## 調色、互動與組裝

移除 Prism／墨綠預設按鈕及其專用樣式，改為背景、面板、浮層、文字、強調色與全站圓角。舊內容的主題值仍可讀取，避免改版破壞既有發布版本。

選取卡片或積木後，可調整顏色、邊框色與粗細、陰影及個別懸停效果；未設定的值沿用全站。支援靜態、浮起、放大、柔光、描邊與慣性傾斜。所有數值透過共用白名單 schema 驗證，不能注入任意 CSS。

選取 frame →「組裝與重用」→命名儲存。每組保留完整子樹、排版與效果，最多 30 積木、8 組；積木庫可新增獨立副本，面板「套用組裝」可替換現有面板。ID 重新產生，副本互不連動，新增／替換／刪除都能復原。單站 100 積木、最多六層；過深或過大的組合會阻擋並提示。

組裝庫只保存在私人草稿，不輸出到公開內容／歷史版本；載入歷史內容時保留當前組裝庫。只在預設中參照的私有素材不會因發布而變成公開；插入實際面板後才成為發布引用。刪除素材仍保護草稿預設中的參照。

## 選取提示與刪除

編輯時藍色虛線標出最內層可選目標，實線標出目前選取。CSS :has 排除同時亮起的父層，與點選選取規則一致，不增加 pointermove 狀態更新。預覽／公開頁不顯示提示。

選取的自訂面板右上角提供 ×，屬性頂端也有「刪除此面板（可復原）」。鎖定時停用直接刪除。代碼展開工作區提供 × 關閉與 Escape，未套用代碼仍保留在面板。

## 部署順序

新增 presentation、appearance 與組裝 presets 均為可選欄位。正式作者 API 必須先部署新版共用 schema，並套用 `202610210001_presentation_media.sql`，才能儲存新設定及原子發布私人品牌／介紹卡素材，再部署前端。無需重設密碼或覆寫草稿。

## 後續效能判斷

若 100 個積木／大型備份出現卡頓，先用 Performance trace 判斷來源：

- 輸入階段長任務：改用路徑更新與結構共享，減少整站 clone／序列化；大型 JSON 驗證可移至 Worker。
- 畫布 commit 偏長：按區塊 memo、視窗外節點延遲渲染，必要時只虛擬化左側長圖層列表。
- 圖片導致網路／解碼抖動：對 URL 欄位做完成驗證與節流、維持圖片尺寸、優先提供最佳化縮圖。
- 儲存延遲：區分網路等待與主執行緒序列化，避免把伺服器延遲誤當成動畫卡頓。保留單一 save queue 與 revision 保護。

先量測再導入 Worker／虛擬化，避免為小型網站增加不必要複雜度。

技術參考：[React useDeferredValue](https://react.dev/reference/react/useDeferredValue)。


## 2026-10-22 操作與版型修正

作者畫布與公開頁面共用相同的容器斷點與排版；裝置寬度代表實際 CSS 寬度，縮放只改變觀看倍率。介紹卡片移動時保留原來的定位方式，放開游標後只儲存位移，不重新進入排版流程。600px 以下依原本閱讀順序顯示，桌面自由位移仍保存在草稿。

兩種工作區均支援：

| 操作 | 快捷鍵 |
| --- | --- |
| 縮放工作區 | Alt＋滾輪（以游標位置為中心） |
| 暫時手形平移 | 按住空格拖曳，或中鍵拖曳 |
| 放大／縮小／100% | Ctrl／Cmd＋加號、減號、0 |
| 撤銷／重做 | Ctrl／Cmd＋Z、Ctrl／Cmd＋Shift＋Z（或 Ctrl／Cmd＋Y） |
| 儲存草稿 | Ctrl／Cmd＋S |
| 刪除所選圖層／積木／腳本 | Delete／Backspace |
| 微調圖層／腳本位置 | 方向鍵 1px；Shift＋方向鍵 10px |

文字輸入欄位保留原生文字撤銷與游標操作；對話框和輸入法組字期間不觸發物件快捷鍵。Alt 在工作區內不啟動瀏覽器選單；切換視窗或失去焦點會解除暫時手形狀態。圖層模式另有 V 選取、M 移動、H 手形；工具列使用 SVG 圖示並提供懸浮名稱與無障礙標籤。

積木模式點擊積木庫只顯示操作提示；使用滑鼠、觸控筆或手指拖入工作區，靠近積木上下緣會高亮吸附位置，放開後緊貼連接。空分支保留可拖放的佔位槽。跨腳本、同一串內重排與巢狀分支使用同一套驗證，禁止容器拖進自己的後代。

點選腳本或積木後，Ctrl／Cmd＋D 可複製；雙擊或 Enter 開啟屬性。鍵盤使用者可先透過上方「＋ 物件腳本」建立並選取腳本，再聚焦積木庫項目按 Enter 加到該腳本末端。

右上即時預覽隨草稿更新，可切換 1280／768／390px 裝置、調整 50–200% 預覽倍率及收合；「執行」開啟可操作的完整互動預覽。小預覽使用獨立的被動文件，避免操作時誤開網站連結或重複執行載入事件。手機將積木庫放在下半部並保留可收合預覽。

新增八種宣告式動作：垂直移動、水平／垂直位置設為、重設變形、文字顏色、圓角、模糊、停止此腳本。沿用原有步數、深度與時間上限；停止積木會結束本次事件，預覽關閉會還原樣式。寬度條件依實際網站容器判斷。

新增動作需要同步部署 `supabase/functions/_shared/schema.ts` 所屬的 `studio-api`，不需要資料表 migration。部署時保留現有 JWT 與雙密碼驗證設定。
