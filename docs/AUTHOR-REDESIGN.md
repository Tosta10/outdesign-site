# 作者工作區改版企畫與實作紀錄

本階段以編輯能力與清楚工作流為優先。公開網站的美術更新由獨立版面處理；作者工作區沿用同一份內容結構、登入驗證、草稿儲存、歷史、復原／重做與發布程序。

## 現況與問題

- 圖層搜尋原先僅隱藏不符合名稱的列，子項目會失去父層脈絡；鎖定、隱藏、刪除的圖層混在同一份長清單。
- 畫布選取深層內容後，左側父項目可能仍然收合。原本調整順序偏重拖曳，缺少可直接使用的同層移動操作。
- 積木庫有分類但缺少搜尋。大部分按鈕點擊僅顯示「請拖曳」；事件按鈕也沒有點擊動作。鍵盤與手機的能力因此不一致。
- 圖層與積木模式本身已有復原、重做、刪除及複製快捷鍵，這次沿用，避免加入另一套相同功能。

## 視覺規劃

採深石墨、低亮青色光、細邊界與明確工作區分隔。亮光集中在目前選取、鍵盤焦點、工作狀態及發布主按鈕，避免持續閃爍和大面積光暈。畫布保留原始公開頁的樣貌；工具介面使用自己的色彩規則。

## 架構邊界

- `src/editor/layer-tree.ts`：純函式，計算搜尋／狀態匹配、祖先路徑；對遺失父層與意外循環有終止保護。
- `src/editor/library-search.ts`：語意多欄位搜尋純函式。
- `LayerExplorer.tsx`：渲染可理解的篩選樹及選取情境，不另建資料來源。
- `ScratchStudio.tsx`：所有新增／套用操作仍由 candidateChange 驗證，接上既有 update 歷史與儲存。
- `editor.css`：工具介面專用樣式。以明確範圍選擇器覆蓋既有工作區樣式，避免影響公開頁。
