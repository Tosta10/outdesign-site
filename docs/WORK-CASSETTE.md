# 玻璃卡帶作品展示：來源分析與實作對照

分析來源：使用者提供的 RhineLabUI-main.zip（約 114 MB）。來源文件中的工作指示僅作為待分析資料，沒有作為本專案的執行指令，也未執行壓縮包的安裝或發布腳本。

## 原專案的技術棧

原始 package.json 使用 TypeScript 5.9.3、Three.js 0.183 系列、Vite 7.3.1；另外使用 @kitlangton/rolling-number 0.4.1。主體是直接操作 DOM 的 TypeScript 應用，沒有 React 或 Vue。GLB 模型由 Blender 工程輸出；Web 版本包含 PWA，另有與 Wallpaper Engine 相關的宿主整合。

README 明確說明視覺參考自既有遊戲宣傳影像。倉庫的 MIT 授權說明的是軟體授權，不能據此假定品牌、美術、字型或影像參考具有同等的使用權。本次不使用該來源的模型、圖片、音訊、品牌、字型、字形路徑與原影片的逐幀標誌軌跡。

## 架構與效果的形成方式

| 模組 | 分析結論 | OutDesign 中的對應 |
| --- | --- | --- |
| main.ts | 總控狀態、檢索、收藏、讀取頁籤、輸入與視圖協調 | index.ts 管理 DOM 與作品狀態，與渲染器分離 |
| scene.ts | 即時陣列、抽取、相機、材質、陰影與後處理 | scene.ts 依狀態更新矩陣、相機和玻璃 |
| motion.ts | 空間波包、相鄰傳播、指數阻尼與精確歸位 | state.ts 的有界波形與與幀率無關的指數收斂 |
| archive-loop.ts | 有限物件池配合無界邏輯索引，循環期間避免反向跳動 | 有限 InstancedMesh 池與循環作品索引 |
| archive-drag.ts | 螢幕拖曳投影、速度取樣、滑行與吸附分離 | Pointer Events、速度取樣、衰減滑行後吸附 |
| boot*.ts | DOM/SVG 與時間軸協調，含逐字、繪線和開場切換 | 原創菱形繪線、校準字樣與可略過的短開場 |
| decryption.ts / glass-reveal.ts | 同一進度驅動材質粗糙度與文字揭示 | 玻璃高度 shader 與文件遮罩共用 reveal |
| model-viewer.ts / viewer-camera.ts | 360° 視角、平移、縮放、復位與六組構件拆解 | 卡帶六組構件與平面作品圖；拖曳、捏合、平移和復位 |
| shared-depth.ts | 透過自訂 MRT 將 AO 法線與 packed depth 共用給景深 | 未移植對引擎內部方法的覆寫，改用官方 SSAOPass、BokehPass |
| quality-renderer.ts | 解析度、陰影、折射採樣及品質預設 | 省電／標準／精細三級，精細啟用 AO／景深 |
| three-resources.ts | 幾何、材質與共享貼圖去重銷毀 | 場景資源去重釋放、事件與觀察器清理 |
| audio.ts | 多軌聲音、事件音效、音樂律動 | 自行合成短音與環境音，不載入任何來源音檔 |
| motion-preferences.ts | 全域及分項減少動態控制 | 系統減少動態、使用者開關、靜態時按需渲染 |
| theme-motion.ts / ui-transitions.ts | 連續配色與可取消轉場，避免快速反向操作遺留動畫 | DOM 動畫先取消再重設，場景狀態連續收斂 |

原作品對視窗投影、陰影 draw coverage、共用深度精度和片段運算做了非常細的效能設計。這些最佳化高度依賴原場景、GLB 和 Three 版本，不能直接假設移到另一個場景仍然有效；本次使用較小的幾何與有限實例池，保留清楚的品質邊界與降級路徑。

## 最終作品形式

依最新指定，「作品」整頁直接進入滿版直立卡帶陣列；選取後展開左側玻璃卡帶、右側作品資料，360° 檢視另有全頁操作介面。真正的作品欄位仍沿用既有作者模式與後端 schema。

封面只建立一個 PlaneGeometry，貼合卡帶表面；圖像薄膜與玻璃共用揭示進度，避免重複折射使作品模糊。圖片以 contain 等比例畫到 CanvasTexture，保留整張內容，不轉成浮雕或立體模型。卡帶轉動時，封面與外殼共用父節點；拆解時，圖片平面與蓋板、襯底等各自移動。作品編號採 NO.001、NO.002 依清單順序產生。收藏使用原始 UUID，不會因排序而指向另一件作品。

卡帶框架、固定構件、標籤、空清單占位圖與驗證用封面均為本次自行製作。未下載外部美術素材，也未打包任何 web 字型；文字使用使用者作業系統的 system-ui／monospace。

## 本專案的模組邊界

- WorkLab.tsx：伺服器輸出可閱讀的作品資料、控制項與備援封面；支援作者選取作品。
- work-lab/state.ts：作品資料轉接、空清單、循環索引、波形、偏好驗證。
- work-lab/index.ts：狀態、搜尋、收藏、匯出、模態對話框、指標／鍵盤／手把輸入、生命週期。
- work-lab/scene.ts：按需載入的 Three.js，實例陣列、圖集、相機、材質、後處理、螢幕尺寸與可見性。
- work-lab/geometry.ts：自行建立卡帶模型，異步封面載入、平面圖像、玻璃 shader、資源釋放。
- work-lab/audio.ts：使用者啟用後才建立 Web Audio 合成音。
- work-lab.css：模組內的介面、明暗配色與容器自適應。

首頁與其他分頁不會載入 Three.js；作者畫布與積木小預覽也會啟動被動 3D 場景，保留圖層選取／拖曳權限；互動預覽才接受訪客操作。隱藏的積木物件索引不建立 WebGL。失去可見性或切到其他分頁會停止渲染。WebGL 不可用時保留真實封面、文字資料、搜尋、收藏與匯出。

PWA、Wallpaper Engine、桌面宿主、日程與系統媒體等不屬於此網站作品展示的功能，沒有引入。

## 全頁陣列與原始動態對齊（2026-10-22 修訂）

先前的平放方盒以 0.68 深度間距排列，卻有 1.92 的幾何深度，會互相穿插；橫縱軸共用 row + lane 索引也使分類與作品錯位。現改為直立薄片，陣列外殼深度 0.22、完整卡帶厚度約 0.483、列間距沿用原版 0.62、寬度 3.44、欄距 4.15，使用 9 × 65 有限實例池。橫向分類各自持有作品列，切列保留該分類記憶位置，邏輯座標持續循環。

依使用者要求，這次直接移植及調整原 MIT 程式中的技術模組，而非先前的簡化替代：

- archive-drag.ts：投影矩陣反解、雙軸速度取樣、反向重估、共同滑行及臨界阻尼吸附。
- motion.ts：原版彈簧方程、肩部位移、分類聚焦、延遲選取波與閒置起伏。
- ui-transitions.ts：可被反向操作中斷的顯示生命週期及面板轉場。
- viewer-camera.ts：球面視角、對數距離內插、短角度路徑與平滑復位。
- @kitlangton/rolling-number 0.4.1：沿用原版的文字與編號滾動技術。

上述原始程式 Copyright (c) 2026 LBEILC，及 rolling-number Copyright (c) 2026 Kit Langton 的 MIT 授權已分別保存在 docs/licenses/。未使用其品牌字形、GLB、圖片、原始字型與音檔，也沒有移植對 Three 引擎的私有 patch。

切列和切檔使用原版 rate 3.7 的保留速度彈簧；肩部與分類焦點預設分別使用 rate 5、6。拖曳依相機投影換算兩軸，放手以 friction 2.4 共同滑行，末段以 rate 10 吸附。舊選取卡帶會先轉正再逐漸歸位，每次移動立即發出波動，待機抬升另有向鄰近卡帶傳播的選取波浪。詳情鏡頭由實際抽取高度推導，並延遲到升起後開始同步玻璃／文件揭示。

UI 對齊原版的角落品牌、右上索引／收藏／導覽、中右作品摘要、左下計數、底部刻度與分類、懸停提示和底部狀態；對品牌與作品資料作 OutDesign 替換。搜尋、收藏、匯出、三級品質、明暗轉場、14 項動畫開關、手機拖曳／雙指、360° 拆解重組均保留。設定入口位於右上導覽選單內，作者入口置於底部，既有作者資料與積木腳本仍可使用。原開場的受保護標誌動畫改為原創菱形動畫；桌面宿主／Wallpaper Engine 專屬功能未作為網站功能引入。

瀏覽器回歸除了截圖與功能點擊，也驗證四方向各自具有中間位置及最終收斂；以 Chromium 原生觸控事件驗證手機拖曳與雙指縮放／平移。48 項單元與安全測試包含投影反解、共同滑行、雙向彈簧與分類索引。

## 作者編輯與即時追蹤（本次修訂）

- 平面封面與陣列圖集共用 64% 的寬高比例；圖片採透明留白和 contain，保留外殼底色。移除頂部綠色底條，以中性灰色編號底條及低反射的灰色頂面替代。
- 明暗切換同時插值整排卡帶、選取卡帶與歸位卡帶的框架、襯底、基板、玻璃和固定件。深色本體預設 #11161c；封面維持原色。淺深色各七種材質色均可編輯。
- 內部場景、頁首、資料、導覽、按鈕與介面文字具有穩定圖層 ID，沿用位置、尺寸、樣式、鎖定／隱藏、復原與重做。作品仍由原本 projects 欄位編輯。編輯器有陣列、資料、360° 被動預覽切換。
- work-lab-config.ts 為圖層、積木和 API 共同的白名單：25 個有限數值、14 項效果、6 類展示選項、14 種材質色。設定隨草稿、版本、發布 JSON 一起儲存，不需改動資料庫結構。
- 積木新增「作品展示」分類：參數、效果、選項、材質色、卡帶操作共五種型別。橋接只接受已知鍵值並限制數值，沿用既有有界解譯器；載入事件等待場景完成初始化。腳本的設定作用於本次執行，清理時還原，不覆寫訪客偏好。
- 相機的相對視角採阻尼，焦點則逐幀跟隨當前卡帶；預設跟隨 rate 24，360° 旋轉／縮放／平移為 20／24／24。持續高速切換使用快速指數追蹤，普通單次切換仍保留原版速度曲線。
- 修正 invalidate 在高頻 pointermove 時重設每幀時鐘的問題。只有從停止／隱藏恢復繪製才重設；低畫質節流也按真正經過時間積分。追蹤回歸以連續長按 100 次、持續拖曳 150 次檢查誤差與每幀時間，不只檢查放手後終點。
- 偵測 SwiftShader／軟體 GPU，自動限制 DPR 並停用重型陰影／後處理；一般 GPU 仍支援三種品質。省電狀態在展示設定中說明。

本機瀏覽器回歸額外包含作者修改設定／文字、復原重做、儲存、積木拖入與修改參數、執行預覽、發布與重載；新設定也受相同的雙密碼、伺服器會話與嚴格 schema 保護。

### 選取待機與材質一致性

瀏覽陣列時，選中卡帶繼續使用原本的 instanced 材質。停止拖曳／滑行／長按並收斂到目標後，等待 selectionDelay（預設 0.45 秒）才抬起卡帶、發出選取波；再次輸入會取消待機。卡帶不會因選取自動切換成另一套玻璃材質，只有明確讀取作品後才進入玻璃詳情。離開選取的抬升代理以原材質歸位，避免快速瀏覽時反覆變色。頂面、頂部邊條及編號底色採共用的灰色配色，深色模式有獨立灰色參數。新參數／顏色在 API 中有相容舊草稿的預設值。

### 移動波動與全站配色

再次對照原檔 scene.ts 的 emitPulse／選取分支、field 的帶正負號 baselineSelectionWave、距離係數 2.2、±0.6 疊加限制及六筆脈衝池。每次切換與投影拖曳現在立即發出移動脈衝；待機抬升的脈衝保留為另一個事件，互不阻擋。灰色頂面改成深度 0.04 的窄邊條，外殼仍為深度 0.22、列距 0.62，保留 0.40 的實體間隙。

設定使用一般六齒輪廓圖示，收在導覽選單內。所有分頁都有全站明暗設定，使用共同的 site-theme 偏好與事件同步；作品的卡帶材質也同步，圖片保持原色。一般頁面使用 CSS 色票，不以反相濾鏡改變作品圖片。舊訪客偏好與無自訂設定的原有頁面仍相容。

低幀率下的閉式彈簧、慣性與相機改依實際幀時間收斂，避免以固定小時間上限累積延遲；隱藏後恢復才重設計時。軟體 GPU 的 DPR 上限改為 0.5，保持 HTML 工具列文字的清晰度，降低大面積三維背景的運算量。

### 載入遮罩、卡帶表面與連續追蹤

所有公開分頁在伺服器 HTML 中先提供載入畫面。場景的首幀、封面載入（有逾時保護）與主要字型準備好後才揭示頁面；內部換頁先蓋住離開的內容，再導向目的頁。新頁同樣以載入畫面開始，瀏覽器返回快取可恢復操作。隱藏或離屏的作者圖層不會阻止整頁完成載入，無 JavaScript 時保留靜態內容。

卡帶頂部細邊離開外殼的共平面，封面與外殼保留深度距離並使用深度偏移。陣列封面使用有透明裁切的非透明排序材質；圖集停用會混入相鄰作品的縮圖 mipmaps，避免遠處或斜角出現碎片和破面。

高速瀏覽只移動實例陣列，不再每跨一格就重建隱藏的玻璃模型、Canvas 與封面材質；需要開啟詳情時才更新。重複按鍵採用快速指數追蹤並清除累積彈簧速度，單次按鍵仍保留原版 3.7 彈簧。波動以輸入時間計算年齡，場域快取共用於高度和傾斜。呼吸保留原碼 8 秒與 13 秒的雙頻起伏，增強幅度並讓待機漸入更早，仍受作者參數、效果開關與減少動態偏好控制。
