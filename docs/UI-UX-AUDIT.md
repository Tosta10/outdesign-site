# UI／UX 盤點與設計規則

2026-10-23，按使用者最新回饋修訂。這份文件補足視覺之外的使用架構。

## 使用者路徑

訪客：首頁理解主題 → 單一作品入口 → 作品操作；另可透過單一導覽閱讀關於／筆記／資源。設定屬觀看偏好，不與內容入口競爭。公開內容不放作者操作教學，不展示無效寄信與假下載。

作者：選頁 → 選物件 → 編輯內容／外觀，或選事件＋加入動作 → 預覽 → 儲存／發佈。圖層是同一內容的結構視圖，積木是同一物件的行為視圖，不新增第二套資料。選取、鎖定與復原需跨視圖一致。

## 問題、處理與驗收

| 問題 | 設計／實作處理 | 驗收 |
| --- | --- | --- |
| 新增雕塑與網站敘事不合 | 移除生成素材，以文字比例／錯位字行／原生捲動字帶組織首頁；停止生圖 | public 無該素材，頁面無該請求 |
| 重複卡片與作品連結降低判斷效率 | 首頁一個作品主入口；關於、筆記、資源各使用適合內容的結構 | 一個主要導覽、設定及作者入口；連結有真實目的 |
| 深色偏好選單同色 | 設定面板獨立主題 tokens，明確 option 背景／前景／color-scheme | 深淺色下標題、選值、選項、焦點均可分辨 |
| 系統原生滑桿突兀且缺少目前狀態 | 清楚的已填／未填軌道、滑塊、數值及鍵盤焦點；保留原生 range 語意 | 端點／中點／方向鍵可操作；觸控區夠大，配色對比明確 |
| 頁面與作者畫布寬度不同導致換行 | 以容器響應式設計，重設舊 hero-copy 48% 寬度 | 320／390／768／1024／1440，文字與操作無重疊／橫溢 |
| 動態搶走閱讀與操作 | 一區一主動態，一次性揭幕與有限字帶位移，原生捲動；減少動態內容立即可見 | 不攔截捲動，停止互動無持續 RAF；鍵盤可取得內容 |
| 筆記開啟方式不直接 | 原生 details 整行開啟；明確加號／關閉態 | Enter 開關，閱讀不依賴 hover |
| 無資料像載入失敗 | 筆記／資源顯式空狀態，無假數字／下載 | 真實空集合及自訂內容均正確 |
| 圖層搜尋失去父子脈絡 | 匹配保留祖先，狀態篩選，選取自動定位 | 祖先、隱藏、鎖定、刪除、排序與復原測試 |
| 積木 click／鍵盤無真實操作 | 搜尋與插入目標明確；click／Enter／觸控真正加入 | 一次操作只加入一次；事件、動作、組裝保持結構合法 |
| 父層鎖定未約束子層 | 圖層面板繼承鎖定狀態，禁用相應操作 | 子層不可拖曳、排序與刪除，資料保留 |
| 作品返回陣列跳變 | 保留揭示值，依鏡頭進度連續恢復陣列覆蓋 | 桌面／手機／減少動態／硬體及軟體繪圖已驗證 |

## 視覺階層與一致性

公開頁：紙白／石墨、大字與開放排版，細線用於分章，不把每個區塊圍成卡片。作品頁保留既有3D場景及操作；共享氣質，採不同閱讀與探索方式。

作者：石墨與微亮青色，光集中在選取／焦點／目前狀態，不使用持續閃爍。正文與互動文字優先可讀，裝飾索引可更小但不承載必要操作。狀態不只靠顏色，另有文字、鎖定／展開／目前值。
