# OutDesign：月面與留白

依據提供的示例圖與 `ai_studio_code.txt` 重構既有系統，保留 OutDesign 品牌與作者內容。

## 五個靜態頁面

| 網址          | 內容                                                 |
| ------------- | ---------------------------------------------------- |
| `/`           | 原有月面首屏、介紹卡與精選作品，不載入完整內容區塊 |
| `/work/`      | 完整作品、分類與詳情                                 |
| `/journal/`   | 可展開的創作筆記                                     |
| `/about/`     | 自我介紹、音樂與聯絡方式                             |
| `/resources/` | 附件下載與外部資源連結                               |

所有頁面由 `SitePage.astro` 共用中繼資料、版本與編輯器入口；`SiteRenderer` 負責框架與首屏，`ContentSection` 提供內容模組。實際網站部署於 `/outdesign-site/`，所有頁面連結均尊重 BASE_PATH。

## 視覺規則

- 畫布 `#0a0a0a`、面板 `#141414`、對話框 `#1c1c1c`，以表面明度與 1px 半透明描邊建立層級。
- 主標題採襯線字，介面採無襯線字，極小的英文索引只作輔助。內容維持繁體中文，可在作者模式修改。
- 原創月面背景為 73,166 bytes WebP；文字、卡片、導覽均為真實 HTML，不把示例圖當成整張網頁。
- 玻璃效果限於首屏介紹卡片與精選卡片，採靜態 24px blur、極低透明度噪點。虹彩限於介紹卡片的 1px 邊界與選取狀態。
- 精選入口採正常文件流，隨主視覺文案高度往下排列；寬螢幕、矮視窗與作者畫布均不與主按鈕重疊。
- 首頁移除常駐「一起聊聊」按鈕；聯絡資訊保留在實際內容區域。
- 手機改為單欄閱讀，卡片保留內容層級，停用透視與昂貴的背景模糊。

## 導覽與動態

右側抽屜使用原生 `dialog` 提供焦點圈限、Escape 關閉與焦點還原。開啟時以 transform／opacity 轉場；目前頁面以 aria-current 標示。

卡片可選靜態、3px 浮起或 1–6 度慣性傾斜。傾斜只作用於介紹、精選入口與作品封面；編輯拖曳時停用。使用事件驅動 RAF，游標離開收斂後停止，切換分頁、視窗或減少動態設定時清理。首頁維持原本面板，取消的 WebGL／水波相關模組已移除。工程藍圖、即時預覽與效能分析見 [STUDIO.md](STUDIO.md)。尊重 reduced-motion，觸控／低更新率裝置使用不透明面板降級。

## 作者畫布

- 桌面：左側頁面與圖層、中央畫布、右側屬性面板；底部工具列可加入作品、筆記與媒體。
- 手機：頁面選擇器、可開合的圖層與屬性面板，避免壓縮畫布。
- 長按排序把手可拖曳作品、筆記與當前分頁內容區塊；滑鼠 180ms、觸控 320ms 啟動，拖曳取消不改資料。
- 方向鍵可替代拖曳，圖層面板也提供上移／下移。一次放下只產生一個復原步驟。
- 拖曳浮標以 requestAnimationFrame 更新 transform；每次拖曳只建立一個浮標。所有事件、pointer capture、RAF 與計時器在取消／卸載時清理。
- 首頁只保留入口；五種內容區塊按分頁顯示，順序以可選的 `layout.sections` 儲存。後端驗證每個區塊恰好出現一次，舊有未包含 layout 的內容保持有效。
- 草稿、自動儲存、素材隱私、雙密碼、版本衝突、復原／重做與發布流程沿用原有伺服器驗證。

圖片生成與素材資訊見 [ASSETS.md](ASSETS.md)；效能數據見 [PERFORMANCE.md](PERFORMANCE.md)。

## 交互與程式碼工作區

- 「互動」面板提供卡片效果、角度、阻尼速度、頁面切換與點擊擴散設定；自定義可查看目前屬性與實際執行的 TypeScript/CSS。
- 「代碼」面板可展開為大工作區。`content.json` 可批次修改所有文字、媒體參照、順序、主題、設計變數與交互設定；套用前使用與後端相同的 Zod schema 驗證，無效內容不會寫入草稿。
- `theme.css` 是型別化 CSS 變數語言，支援八項全站設計屬性。僅允許 `.site` 區塊、已列出的變數、六位色碼與有限範圍整數 px，拒絕外部載入與任意選擇器。任意 JS、HTML 模板及建置設定仍於 GitHub 原始碼修改。
- 代碼套用形成單一復原步驟；未套用代碼保留在面板，切換檔案或重載前提示捨棄。若草稿已在別處更新，停用套用，避免覆蓋新資料。
- 跨文件 View Transitions 漸進增強普通靜態導航，無支援的瀏覽器使用輕量內容淡入；選擇無轉場及系統 reduced-motion 時皆停用。跨頁保留瀏覽器正常返回與直接網址存取。

## Figma 參考與新版作者工作區

參考 Figma 官方 [Auto Layout](https://help.figma.com/hc/en-us/articles/360040451373-Guide-to-auto-layout-in-Figma)、[Frames](https://help.figma.com/hc/en-us/articles/360041539473-Frames-in-Figma-Design) 與 [Constraints](https://help.figma.com/hc/en-us/articles/360039957734-Apply-constraints-to-define-how-layers-resize) 的框架、方向、間距、填滿與固定尺寸原則，將其轉成可發布的網站元件模型。

- 單一選取來源：左側頁面／圖層與畫布選取共同決定右側屬性，移除「編輯區塊」下拉選單；切換頁面自動選取該頁內容。
- 編輯模式不啟動 viewer 事件，攔截 click、鍵盤啟用與中鍵開啟；作品對話框、連結、筆記、音訊與選單只在預覽啟用。
- 主題只保留 Prism 與 Verdant 墨綠。後者使用 `#080f0d / #111d18 / #1b2b23` 與霧銀綠 `#91c4a5`；維持相同資訊層級、細描邊與虹彩節制。切換主題同步換上完整視覺變數；舊主題名稱在資料解析時轉為 Prism。
- 自訂圖層為扁平 parent-ID 樹，支援 frame／text／image／link／divider。最多 100 層，樹深最多六層，伺服器拒絕孤兒、跨頁父層、循環與重複 ID。
- 面板支援垂直、水平換行、網格與自由定位；有尺寸、間距、內距、對齊、色階、字級、圓角、透明度、顯示與鎖定。可新增、複製子樹、刪除子樹與變更父層。
- 自由定位使用百分比 X、px Y；游標移動與縮放期間只畫 transform，放開才提交座標／尺寸，形成單一復原步驟。8px 吸附可關閉，方向鍵微調，Shift+方向鍵為 1px。
- 手機畫布將自由定位轉為文件順序與單欄閱讀，避免固定座標造成水平溢出。公開頁與編輯畫布共用 container queries；裝置寬度與縮放只改工作區視圖。
- 每頁可調自訂面板間距、留白、前後位置，以及停用原有主視覺／預設內容；保留全站導覽與頁尾。
- 所有屬性面板附有獨立 JSON 編輯器，套用前以完整 schema 驗證，資料變更時防止舊代碼覆蓋新狀態。素材面板編輯的是引用與顯示資料，二進位上傳仍由素材工具處理。

這是網站用途的框架與排版編輯系統，未包含 Figma 的向量路徑工具、多人即時協作或任意程式碼執行。
