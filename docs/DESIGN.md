# Step 3：OutDesign 視覺與互動設計

## 頁面結構

1. 導覽：OutDesign 標誌、作品／筆記／關於與聯絡入口。手機顯示可展開選單。
2. 首屏：大字雙行標題、簡短自我定位、作品入口，右側原創金屬圓環。手機改為標題、說明、圖像的單欄順序。
3. 精選作品：分類按鈕、固定比例封面、作品名稱與年份；點選開啟詳情，外部網址有獨立入口。
4. 筆記：日期與標題列表，點選展開文字，降低長內容的掃讀負擔。
5. 關於：自我介紹、個人標籤與主動播放的音樂元件。
6. 資源：有附件時才顯示，保留檔案名稱與下載資訊。
7. 聯絡與頁尾：大型邀請語句、Email、社群與低干擾的作者入口。

## 核心 CSS variables

實際定義在 `src/styles/site.css`，以 CSS cascade layers 組織。

| 變數 | 預設 | 用途 |
| --- | --- | --- |
| `--color-bg` | `#0b0b0d` | 主要深黑背景 |
| `--color-surface` | `#141416` | 表面層級 |
| `--color-raised` | `#1b1b1f` | 浮層 |
| `--color-text` | `#eeeef0` | 柔白正文 |
| `--color-muted` | `#9b9ba3` | 次要說明 |
| `--color-line` | `#27272d` | 內容分隔 |
| `--color-white` | `#fafaf8` | 主要動作 |
| `--color-accent` | `#c8b9ed` | 焦點與選取 |
| `--gradient-prism` | 紫／藍／淺綠／粉 | 小面積虹彩引導 |
| `--page-width` | `1280px` | 閱讀區上限 |

## 虹彩與動態的功能

- 小型品牌記號、主要聯絡入口、分隔線起點提供視覺定位。
- 編輯中的區塊以選取框清楚標示；風格選項有勾選圖示與文字。
- 作品封面僅在互動時微幅縮放，避免持續占用繪製資源。
- 音訊指示僅在實際播放時動畫；播放失敗有文字回饋。
- 成功、失敗、儲存中都有文字，未以虹彩取代語意。
- `prefers-reduced-motion: reduce` 停用動畫與平滑捲動。

Prism 採克制虹彩；Quiet 使用黑白與灰階主視覺；Luminous 增強虹彩與極淡的靜態底光。三者共用內容、字體與間距規則。

## 編輯操作

桌面以右側面板配合頁面預覽；手機以可開合的全寬面板避免擠壓畫面。作品排序另提供上移／下移按鈕，觸控與鍵盤都可使用。每次編輯記錄於可撤銷的記憶體歷史，自動儲存成功才顯示「所有修改已儲存」。
