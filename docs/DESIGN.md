# OutDesign：月面與留白

依據提供的示例圖與 `ai_studio_code.txt` 重構既有系統，保留 OutDesign 品牌與作者內容。

## 五個靜態頁面

| 網址          | 內容                                                 |
| ------------- | ---------------------------------------------------- |
| `/`           | 月面首屏、介紹入口與單一精選作品，不載入完整內容區塊 |
| `/work/`      | 完整作品、分類與詳情                                 |
| `/journal/`   | 可展開的創作筆記                                     |
| `/about/`     | 自我介紹、音樂與聯絡方式                             |
| `/resources/` | 附件下載與外部資源連結                               |

所有頁面由 `SitePage.astro` 共用中繼資料、版本與編輯器入口；`SiteRenderer` 負責框架與首屏，`ContentSection` 提供內容模組。實際網站部署於 `/outdesign-site/`，所有頁面連結均尊重 BASE_PATH。

## 視覺規則

- 畫布 `#0a0a0a`、面板 `#141414`、對話框 `#1c1c1c`，以表面明度與 1px 半透明描邊建立層級。
- 主標題採襯線字，介面採無襯線字，極小的英文索引只作輔助。內容維持繁體中文，可在作者模式修改。
- 原創月面背景為 73,166 bytes WebP；文字、卡片、導覽均為真實 HTML，不把示例圖當成整張網頁。
- 玻璃效果限於首屏介紹卡片與精選卡片，採靜態 24px blur、極低透明度噪點。虹彩限於介紹卡片的 1px 邊界與選取狀態。
- 首頁移除常駐「一起聊聊」按鈕；聯絡資訊保留在實際內容區域。
- 手機改為單欄閱讀，卡片保留內容層級，停用透視與昂貴的背景模糊。

## 導覽與動態

右側抽屜使用原生 `dialog` 提供焦點圈限、Escape 關閉與焦點還原。開啟時以 transform／opacity 轉場；目前頁面以 aria-current 標示。

卡片可選靜態、3px 浮起或 1–6 度慣性傾斜。傾斜只作用於介紹、精選入口與作品封面；編輯拖曳時停用。使用事件驅動 RAF，游標離開收斂後停止，切換分頁、視窗或減少動態設定時清理。無自動旋轉、粒子、捲動劫持或全頁 WebGL。尊重 reduced-motion，觸控／低更新率裝置使用不透明面板降級。

## 作者畫布

- 桌面：左側頁面與圖層、中央畫布、右側屬性面板；底部工具列可加入作品、筆記與媒體。
- 手機：頁面選擇器、可開合的圖層與屬性面板，避免壓縮畫布。
- 長按排序把手可拖曳作品、筆記與當前分頁內容區塊；滑鼠 180ms、觸控 320ms 啟動，拖曳取消不改資料。
- 方向鍵可替代拖曳，圖層面板也提供上移／下移。一次放下只產生一個復原步驟。
- 拖曳浮標以 requestAnimationFrame 更新 transform；每次拖曳只建立一個浮標。所有事件、pointer capture、RAF 與計時器在取消／卸載時清理。
- 首頁只保留入口；五種內容區塊按分頁顯示，順序以可選的 `layout.sections` 儲存。後端驗證每個區塊恰好出現一次，舊有未包含 layout 的內容保持有效。
- 草稿、自動儲存、素材隱私、雙密碼、版本衝突、復原／重做與發布流程沿用原有伺服器驗證。

圖片生成與素材資訊見 [ASSETS.md](ASSETS.md)；效能數據見 [PERFORMANCE.md](PERFORMANCE.md)。

## 交互與程式碼工作區

- 「互動」面板提供卡片效果、角度、阻尼速度、頁面切換與點擊擴散設定；自定義可查看目前屬性與實際執行的 TypeScript/CSS。
- 「代碼」面板可展開為大工作區。`content.json` 可批次修改所有文字、媒體參照、順序、主題、設計變數與交互設定；套用前使用與後端相同的 Zod schema 驗證，無效內容不會寫入草稿。
- `theme.css` 是型別化 CSS 變數語言，支援八項全站設計屬性。僅允許 `.site` 區塊、已列出的變數、六位色碼與有限範圍整數 px，拒絕外部載入與任意選擇器。任意 JS、HTML 模板及建置設定仍於 GitHub 原始碼修改。
- 代碼套用形成單一復原步驟；未套用代碼保留在面板，切換檔案或重載前提示捨棄。若草稿已在別處更新，停用套用，避免覆蓋新資料。
- 跨文件 View Transitions 漸進增強普通靜態導航，無支援的瀏覽器使用輕量內容淡入；選擇無轉場及系統 reduced-motion 時皆停用。跨頁保留瀏覽器正常返回與直接網址存取。
